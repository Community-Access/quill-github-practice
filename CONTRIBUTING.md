# Contributing

This repository is the example everyone practises from, so it stays as it is:
only Community Access changes it. To practise contributing, make a copy of
your own, as the README describes, and contribute to that.

In your copy, the usual habits apply:

- Open an issue before a large change, so others can say what they think.
- Make your change on a branch of its own, and open a pull request.
- Add a test with each change, and check that the tests pass:
  `python -m unittest discover -s tests`.
- Keep the code small and readable. Tally is meant to stay easy to follow.

If you find a mistake in the practice material itself, email
support@community-access.org.
