# Contributing

This is a practice repository, so every contribution is welcome, including
ones that are only practice.

- Open an issue before a large change, so others can say what they think.
- Make your change on a branch of its own, and open a pull request.
- Add a test with each change, and check that the tests pass:
  `python -m unittest discover -s tests`.
- Keep the code small and readable. Tally is meant to stay easy to follow.

If you're practising something that changes the repository, such as merging
or closing issues, please do it in your own copy instead. The README says how
to make one.
